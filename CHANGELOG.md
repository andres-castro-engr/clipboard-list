# Change Log

All notable changes to the "clipboard-list" extension will be documented in this file.

## [1.0.0] - 2026-09-23

- Initial major release of Clipboard List.
- Automatic clipboard tracking retaining the last 10 copied items.
- MRU (Most Recently Used) list ordering with duplicate prevention.
- Instant pasting via key number shortcuts (`Ctrl+Alt+V 1` through `Ctrl+Alt+V 0`).
- Interactive QuickPick clipboard history viewer (`Ctrl+Alt+V` / `Cmd+Alt+V`).
- Status bar indicator displaying current clipboard count and quick access.
- Official extension icon and metadata.
